## ⚠️ КРИТИЧЕСКИЕ ОГРАНИЧЕНИЯ

### Проблема 1: Отсутствие FreeCAD

**Ситуация**: В среде разработки отсутствует FreeCAD, и нет возможности его установить:
- Нет прав на `apt-get install`
- Ограничен доступ к внешним ресурсам (только github.com, pypi.org)
- FreeCAD недоступен через pip

**Последствия**:
- ❌ Невозможно создать полноценный FCStd файл с PartDesign телами и историей построения
- ❌ Невозможно сделать рендеры модели
- ❌ Невозможно экспортировать в STEP
- ❌ Невозможно проверить пересечения и "висящие" детали
- ❌ Невозможно настроить подвижные связи в Assembly

**Решение**: Создан скрипт `GRN471_FreeCAD_script.py`, который нужно запустить в FreeCAD для создания полноценной модели.

**Попытка решения**: Команда `gh repo edit --visibility private` вернула ошибку:

**Решение**: Только владелец репозитория может сделать его приватным:

2. Прокрутите вниз до "Danger Zone"
3. Нажмите "Change repository visibility"
4. Выберите "Make private"

## 🔧 КАК ЗАВЕРШИТЬ МОДЕЛЬ

### Шаг 1: Установить FreeCAD

Скачайте FreeCAD 1.0 или новее:
- Официальный сайт: https://www.freecad.org/downloads.php
- Для Linux: `sudo apt-get install freecad`
- Для Windows: скачать установщик с сайта

### Шаг 2: Запустить скрипт

1. Откройте FreeCAD
2. Macro → Macros... → Execute
3. Выберите файл `scripts/GRN471_FreeCAD_script.py`
4. Дождитесь завершения (~200 объектов)

**Результат**:
- Создастся документ `GRN471_Kolibri`
- Все узлы и детали будут созданы как PartDesign Body
- Таблица параметров будет заполнена
- Модель сохранится в `GRN471_Kolibri.FCStd`

### Шаг 3: Проверить геометрию

1. Проверьте, что все детали на своих местах
2. Убедитесь, что нет пересечений (Part → Check geometry)
3. Проверьте, что детали не "висят в воздухе"

### Шаг 4: Настроить Assembly

1. Создайте Assembly контейнер
2. Добавьте все узлы
3. Настройте связи (Joints):
   - **Вращение ротора**: Revolute joint, 66 об/мин
   - **Поворот штанг**: Cylindrical joint (по кольцевой дорожке)
   - **Вращение колес**: Revolute joint (свободное)
   - **Подъем ограждений**: Revolute joint (шарнир)
   - **Перемещение отражателя**: Prismatic joint
   - **Ход винтов**: Screw joint

### Шаг 5: Создать разнесённые виды

1. Выделите узел (например, Ротор)
2. Assembly → Create Exploded View
3. Настройте направления и расстояния
4. Повторите для Каретки и других узлов

### Шаг 6: Сделать рендеры

1. Переключитесь в верстак Raytracing
2. Создайте сцену POV-Ray
3. Настройте камеру и освещение
4. Отрендерируйте views:
   - Общий вид (изометрия как на картинке-образце)
   - Вид сверху
   - Вид сбоку
   - Ротор крупно
   - Каретка крупно
   - Разнесённый вид ротора
   - Разнесённый вид каретки

### Шаг 7: Экспортировать в STEP

В консоли FreeCAD:
```python
import Part
doc = FreeCAD.ActiveDocument
Part.export([obj for obj in doc.Objects if hasattr(obj, "Shape")], "GRN471_Kolibri.step")
```

### Шаг 8: Обновить релиз

1. Загрузите новые файлы в релиз:
   - Обновленный FCStd
   - STEP файл
   - Рендеры (PNG/JPG)
2. Обновите описание релиза
