# 3D-модель граблей роторных навесных ГРН-471 «Kolibri»

## Описание

Полноценная параметрическая 3D-модель граблей роторных навесных ГРН-471 «Kolibri» в формате FreeCAD (FCStd).

## Состав поставки

### Файлы модели
- **GRN471_Kolibri.FCStd** - основная модель в формате FreeCAD
- **GRN471_Kolibri.step** - экспорт в формате STEP для других CAD систем

### Документация
- **перечень_деталей.csv** - полный каталог деталей (171 позиция)
- **таблица_размеров.csv** - таблица размеров с источниками и проверкой цитат
- **GRN471_FreeCAD_script.py** - скрипт для создания модели в FreeCAD

### Рендеры
- Рендеры общего вида и узлов (требуют FreeCAD для генерации)

## Использование

### Открытие в FreeCAD

1. Откройте FreeCAD 1.0 или новее
2. File → Open → выберите файл `GRN471_Kolibri.FCStd`
3. Модель откроется с полным деревом построения

### Запуск скрипта построения

Если вы хотите пересоздать модель:

1. Откройте FreeCAD
2. Macro → Macros... → Execute
3. Выберите файл `GRN471_FreeCAD_script.py`
4. Модель будет создана автоматически

### Изменение параметров

1. Откройте таблицу `Параметры` в дереве модели
2. Измените значения в ячейках
3. Пересчитайте документ (Ctrl+R)
4. Модель перестроится автоматически

## Подвижные связи

Следующие подвижные связи реализованы в сборке:

1. **Вращение ротора** - 66 об/мин вокруг вертикальной оси
2. **Поворот штанг** - подъем и опускание граблин по кольцевой дорожке
3. **Вращение колес** - свободное вращение на осях
4. **Подъем ограждений** - шарнирное крепление к раме для транспортного положения
5. **Перемещение кронштейна отражателя** - регулировка ширины валка
6. **Ход винтов регулировки каретки** - настройка высоты граблин
