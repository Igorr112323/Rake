## КАК ЗАВЕРШИТЬ МОДЕЛЬ

### Шаг 1: Запустить скрипт в FreeCAD

1. Установите FreeCAD 1.0 или новее
2. Откройте FreeCAD
3. Macro → Macros... → Execute
4. Выберите файл `scripts/GRN471_FreeCAD_script.py`
5. Дождитесь завершения (создастся ~200 объектов)

### Шаг 2: Проверить геометрию

1. Проверьте, что все детали на своих местах
2. Убедитесь, что нет пересечений
3. Проверьте, что детали не "висят в воздухе"

### Шаг 3: Настроить Assembly

1. Создайте Assembly контейнер
2. Добавьте все узлы
3. Настройте связи (Joints):
   - Revolute для вращающихся частей
   - Prismatic для поступательных
   - Cylindrical для сложных движений

### Шаг 4: Создать разнесённые виды

1. Выделите узел (например, Ротор)
2. Assembly → Create Exploded View
3. Настройте направления и расстояния

### Шаг 5: Сделать рендеры

1. Переключитесь в верстак Raytracing
2. Создайте сцену POV-Ray
3. Настройте камеру и освещение
4. Отрендерируйте views:
   - Общий вид (изометрия)
   - Вид сверху
   - Вид сбоку
   - Ротор крупно
   - Каретка крупно
   - Разнесённый вид

### Шаг 6: Экспортировать

```python
# В консоли FreeCAD:
import Part
doc = FreeCAD.ActiveDocument
Part.export([obj for obj in doc.Objects if hasattr(obj, "Shape")], "GRN471_Kolibri.step")
```
